Rocket Controller:
- Only a controller.
- Controls/Manages GPIO pins.
- Automatically deploys parachute when conditions met.
- Shutdown pins or sensors remotely.
- Gets sensor data and for transmission.

COMMANDS:
- "Manual Parachute Deployment": Deploy parachute manually.

- "Disable/Enable Automatic Deployment": Disable/Enable automatic deployment.

- "Shutdown": Shutdown the entire rocket computer.

- "Disable/Enable Sensor Data Transmission": Disable/Enable sensor transmission.
- "Disable/Enable Receiving": "Disable/Enable transceiver receiving."

- "Disable/Enable Local Onboard Raspi-Camera": Disable/Enable Raspi-Camera.
